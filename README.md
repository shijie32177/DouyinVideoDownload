# 抖音视频下载工具

一个基于 PyQt5 开发的桌面应用程序，通过 DrissionPage 驱动 Chrome 浏览器抓取抖音视频，支持收藏夹、我的作品、我的喜欢、发现用户及分享链接解析等多种下载模式。

## 功能特点

- **我的** — 登录后一键同步：
  - 收藏夹：按文件夹浏览，支持缓存与增量刷新
  - 我的作品：抓取自己发布的所有视频
  - 我的喜欢：抓取自己点赞的所有视频
- **发现** — 通过 UID 或主页链接搜索任意用户，查看其作品/喜欢列表并批量下载
- **下载** — 统一下载中心，支持：
  - 断点续传（暂停 / 继续 / 取消）
  - 全局控制（全部开始 / 暂停 / 取消）
  - 自定义下载目录
  - 导出视频链接列表
  - 实时进度显示
- **解析** — 粘贴抖音 App 分享文本，自动提取视频直链并加入下载队列，保留历史解析记录
- **多主题** — 内置 4 套主题：深色（默认）、午夜蓝、翠绿极简、暖沙浅色
- **设置** — 可配置最大并发下载数、我的作品 / 喜欢同步上限

## 环境要求

- Python 3.8+
- Google Chrome 浏览器（由 DrissionPage 驱动）
- 依赖包：

```bash
pip install PyQt5 PyQtWebEngine requests DrissionPage
```

## 运行程序

```bash
python app.py
```

## 使用说明

### 首次使用 / 登录

1. 启动程序后切换到 **「我的」** 标签页
2. 内嵌浏览器会打开抖音网页版，完成扫码或账号密码登录
3. 登录成功后 Cookie 自动保存，后续启动无需重复登录

### 我的收藏 / 我的作品 / 我的喜欢

1. 在「我的」下选择对应子标签
2. 点击「同步」按钮抓取视频列表（支持设置同步上限）
3. 勾选视频后点击「提取到下载中心」，或直接点击视频卡片上的下载按钮

### 发现用户

1. 在「发现」标签页输入 UID（`MS4wLjABAAAAxxx`）或用户主页链接
2. 点击「搜索 / 添加用户」，程序自动解析用户信息
3. 选择查看「作品」或「喜欢」列表，勾选后批量下载

### 解析分享链接

1. 在「解析」标签页粘贴抖音 App 分享复制的文本（含 `https://v.douyin.com/…` 短链）
2. 点击「解析视频」，程序自动提取直链
3. 点击「加入下载」将视频加入下载中心

### 下载中心

- 在「下载」标签页查看所有任务
- 使用顶部全局按钮控制所有任务，或逐条操作
- 点击「打开目录」可直接定位到已下载文件

## 工作原理

抖音视频直链获取流程：

1. 解析短链重定向，提取 `aweme_id`
2. 尝试官方 API（`/aweme/v1/feed/`）获取下载地址
3. 若 API 失败，通过 DrissionPage 驱动 Chrome 拦截 `aweme/detail` 网络请求获取真实 URL
4. 使用 `requests` 多线程下载

Cookie 文件保存于 `~/.douyin_tool_cookie`，浏览器 Profile 保存于 `~/.douyin_drission_profile`。

## 注意事项

- 请确保本地已安装 Google Chrome，并与 DrissionPage 版本匹配
- 下载速度受网络条件和抖音服务器限制影响
- 请遵守抖音使用条款及相关版权规定，仅供个人学习使用
- 视频文件默认保存至程序目录下的 `videos/` 文件夹
